# Voice Pyramid Reference Build — Assembly

> Early development documentation. Final assembly and power instructions must be verified on physical hardware before release.

The intended assembly is deliberately minimal:

1. Attach the supported AtomS3R controller to the Voice Pyramid using the manufacturer's intended Atom interface.
2. Use USB on the AtomS3R for initial firmware flashing as documented by OpenAthan.
3. Use the final documented Voice Pyramid power connection for normal operation.

No soldering or custom PCB assembly should be required for the reference build.
