# Optional Hardware Expansions

These are possible future additions, **not currently supported accessories** or
required purchases. Use the [hardware guide](../README.md) for installable builds.

Potential future expansions include:

- battery-backed RTC for improved operation across power/network outages;
- microSD or USB mass storage for offline Quran audio;
- external speaker/audio output options;
- alternate compatible Atom controllers or speaker bases.

Expansion hardware should remain optional unless it becomes necessary for core reliability.

The Waveshare Box V2's existing onboard clock is part of that model, rather than
an add-on. Powered-restart restoration is supported; unplugged retention and
battery behavior remain unqualified. Other clock adapters require separate work.
