# OpenAthan v0.8.0

**Release candidate — not yet published.**

## What's included

- **Dua after Athan**, an optional audio setting, off by default. Plays the
  approved dua once, two seconds after a scheduled Athan finishes, at the current
  Athan volume. It works with normal and Fajr Athan; a shared Isha/Fajr event
  plays one dua.
- Existing speakers download the recording over Wi-Fi when this setting is
  enabled. The settings page shows installation progress and Retry when needed.
  Once installed, it works offline. Fresh-install bundles already include it.
- Stop, muting or turning the setting off cancels the remaining dua. The Stop
  controls remain available during the silent pause. Firmware checks, updates,
  Quran playback and setup wait for shared audio or installation work to finish.

## Install and update

Supported hardware remains AtomS3R C126 + Voice Pyramid A167 and Waveshare
ESP32-S3-Touch-LCD-1.85C-BOX V2. Waveshare V1 is not supported.

After publication, update from the speaker's settings page to preserve Wi-Fi,
speaker password, prayer settings and history. Then enable **Dua after Athan**
under audio settings. Installation waits for a safe gap before the next prayer;
keep the speaker powered and connected until it shows **Ready**.

A fresh installation through [the USB installer](https://openathan.com/install/)
erases existing firmware, credentials, settings and prayer history. Use USB
recovery to change Wi-Fi or recover a forgotten speaker password.

## Testing and limitations

Attended development-firmware tests on both reference boards confirmed complete
normal/Fajr Athan and dua, Stop during dua, offline shared Isha/Fajr playback,
interrupted-download recovery and restoration of production records and audio.
See the [attended report](../development/dua-attended-validation-2026-10-20.md)
and [release preparation](../development/v0.8.0-preparation-2026-10-20.md) for
source identities, automated checks and remaining runtime and release-image
qualification limits. These development results do not establish installation,
update or recovery acceptance of the final signed release images.

The previously observed Samsung Galaxy S9 hostname issue remains: use the
speaker's current IP address if its `.local` address will not open. Full physical
phone setup through location review and Finish setup remains separately pending.

Normal/Fajr recordings are unchanged. The dua uses the owner's approved recording
from the same source under the same redistribution permission. See
[recording attribution and permission](../../AUDIO-LICENSES.md).
