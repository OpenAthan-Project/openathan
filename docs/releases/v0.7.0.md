# OpenAthan v0.7.0

**Release candidate — not yet published.**

## What's included

- Install now, set up later. Finish installing OpenAthan without entering Wi-Fi
  details or choosing a speaker password. Continue setup on the computer or use
  a phone when you're ready.
- Set up from your phone. Scan the speaker's Wi-Fi QR code to join its temporary
  setup network. Use the automatic setup page or open
  `http://192.168.4.1/setup/`, then choose a speaker password and connect to home
  Wi-Fi.
- Find your speaker again without a bookmark. While audio is idle, briefly press
  the Atom front button or Waveshare BOOT button to see connection information.
  Atom shows the webpage QR and addresses on separate screens; Waveshare shows
  them together. During playback, the button still stops audio.

## Install and update

Supported hardware remains AtomS3R C126 + Voice Pyramid A167 and Waveshare
ESP32-S3-Touch-LCD-1.85C-BOX V2. Waveshare V1 is not supported.

After publication, update from the speaker's settings page to keep its Wi-Fi,
speaker password, prayer settings and history.
Use [USB recovery](https://openathan.com/install/) to change Wi-Fi or recover a
forgotten speaker password.

Initial phone setup uses an open temporary Wi-Fi network; perform setup in a
trusted place.

A fresh installation erases existing firmware, credentials, prayer settings and
prayer history. When setting up by phone, power Atom through the Pyramid's bottom
USB-C port only, or Waveshare through its rear USB-C port. After joining home
Wi-Fi, sign in as **admin** with the chosen speaker password, review location and
prayer times, and select **Finish setup**. Scheduled Athan waits for a valid clock.

## Known issues and testing

The `.local` address did not open on the tested Samsung Galaxy S9 running Android
10. Opening the speaker's current IP address worked, including signing in and
refreshing after a cold restart. If the hostname won't open, use the IP address
shown on the speaker. Keep the phone and speaker on the same home Wi-Fi.

Testing on development firmware covered QR scanning, setup-page access and saved
network access after a cold restart. Physical testing of the complete phone setup
flow and installation, update and recovery of the final release builds is still
pending. Memory use with audio, Wi-Fi and the screen active together has not been
measured on this candidate. See the [validation report](https://github.com/OpenAthan-Project/openathan/blob/6b5eb795167a2f7af545e7813b884fa716d49d53/docs/development/v0.7.0-preparation-2026-10-17.md)
for detailed results and remaining checks.

The included Athan recordings and their attribution are unchanged. See
[AUDIO-LICENSES.md](https://github.com/OpenAthan-Project/openathan/blob/6b5eb795167a2f7af545e7813b884fa716d49d53/AUDIO-LICENSES.md).
