# OpenAthan v0.7.0

**Release candidate:** publication and stable/latest selection are pending.

## What's included

- Install OpenAthan first and set up the speaker later. On a fresh installation,
  choose phone setup or continue on the computer; Wi-Fi and a speaker password
  are not required to finish installing phone-capable firmware.
- Set up from a phone by joining the speaker's temporary setup Wi-Fi. Scan the
  screen's Wi-Fi QR, use the automatic setup page or enter
  `http://192.168.4.1/setup/`, then choose a speaker password and home Wi-Fi.
- Find the speaker's page again without a bookmark. While audio is idle, briefly
  press the Atom front button or Waveshare BOOT button for connection information.
  Atom shows the webpage QR and addresses on separate screens; Waveshare shows
  them together. A press during playback continues to stop audio.
- Use the displayed current IP address if the `.local` hostname does not open.
  Keep the phone and speaker on the same home Wi-Fi.

## Install and update

Supported hardware remains AtomS3R C126 + Voice Pyramid A167 and Waveshare
ESP32-S3-Touch-LCD-1.85C-BOX V2. Waveshare V1 is not supported.

After publication, use the signed updater on an existing speaker's settings page
to preserve saved data. Updating an already configured speaker keeps its Wi-Fi,
speaker password and prayer settings; it does not reopen first-run enrollment.
Use [USB recovery](https://openathan.com/install/) to change Wi-Fi or recover a
forgotten speaker password.

Initial phone setup uses an open temporary Wi-Fi network; perform setup in a
trusted place.

A fresh installation erases existing firmware, credentials, prayer settings and
prayer history. When setting up by phone, power Atom through the Pyramid's bottom
USB-C port only, or Waveshare through its rear USB-C port. After joining home
Wi-Fi, sign in as **admin** with the chosen speaker password, review location and
prayer times, and select **Finish setup**. Scheduled Athan waits for a valid clock.

## Validation and limits

Development checks cover phone Wi-Fi QR scanning, automatic/manual setup-page
entry, authenticated local-page access and source-bound restart/preservation
cases. These observations are separate from exact release-image acceptance.
Some tested Samsung hostname requests failed while direct-IP sign-in and refresh
worked; the cause remains unresolved, so the current-IP fallback is important.

The complete physical phone prayer-setup wizard, additional failure/recovery
cases and runtime heap/fragmentation/PSRAM under concurrent activity remain
unobserved or unmeasured in the recent setup sessions. See the
[release preparation and acceptance report](../development/v0.7.0-preparation-2026-10-17.md)
for the exact tested sources and remaining publication checks.

Stored Athan recordings, attribution and media approval remain unchanged in
[AUDIO-LICENSES.md](../../AUDIO-LICENSES.md).
