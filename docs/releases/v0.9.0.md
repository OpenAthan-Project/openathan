# OpenAthan v0.9.0

Proposed release; not published. See the
[preparation and qualification record](../development/v0.9.0-preparation-2026-10-27.md).

## What's included

- **Waveshare ESP32-S3-AUDIO-Board support**, alongside AtomS3R C126 with Voice
  Pyramid A167 and Waveshare Box V2. The AUDIO-Board has no screen and uses its
  USB-C port for power and setup.
- The same on-device prayer calculations, stored normal/Fajr Athan, Quran over Wi-Fi,
  optional dua, phone settings and signed updates. The public website and Home
  Assistant are not needed for everyday prayer scheduling.
- **KEY1 lowers volume, KEY2 stops playback, and KEY3 raises volume.** Volume
  changes in five-percentage-point steps, stays within 0–100% and is saved.
  Holding a volume key produces one step. BOOT retains Stop, about three seconds
  to skip the next Athan and about seven seconds to cancel that skip.
- All seven RGB LEDs follow the existing prayer colours together. Brightness
  and the lights switch remain available on the phone page. On restart, RTC
  time is restored only when it passes validation.

Stored Athan and installed dua can play without internet once the clock is
valid. Quran streaming requires internet. If no valid clock is available after
restart, Wi-Fi time synchronization is required before scheduled playback.

## Install and update

Check the exact board model before installation. The AUDIO-Board and Box V2 use
different firmware; ESP32-S3 detection alone cannot identify them. Box V1 and
other Waveshare models are not supported by these profiles.

For a new AUDIO-Board, use a USB data cable and select the matching model in the
[USB installer](https://openathan.com/install/). A fresh installation erases
existing firmware, Wi-Fi, settings and prayer history. Initial qualification
uses USB power; microphones, SD storage, external displays and battery features
are outside this release's AUDIO-Board support.

Join the speaker's temporary setup Wi-Fi and open `http://192.168.4.1/setup/`.
Complete the wizard, return to home Wi-Fi and bookmark the speaker address shown
during setup. If its `.local` address does not open, use its current IP address;
USB setup can read both addresses and repair Wi-Fi or the speaker password.
Review the location and prayer timetable, then finish setup on the speaker page.

For an existing OpenAthan speaker, use **Install update** on its authenticated
settings page or the preserving USB update flow. These application updates retain
settings, credentials, prayer history and shared recordings. Fresh installation
is not an update or password-recovery method. Keep power connected until writing,
verification and startup checks finish. On the AUDIO-Board, press RESET only
when the USB updater's completion instructions ask for it.

## Testing and limitations

One USB-powered AUDIO-Board passed attended normal/Fajr/dua and Quran playback,
controls, lights, phone setup, scheduled playback and powered RTC restart at the
sources recorded in the [hardware report](../development/waveshare-audio-board-hardware-2026-10-21.md).
Later private signed-update, interruption, rollback and one-hour runtime checks
are recorded [separately](../development/waveshare-audio-board-upgrades-2026-10-26.md).
The tested unit's PCB revision marking remains unknown; other units need their
own hardware preflight.

An isolated test's Wi-Fi wizard returned to setup; USB provisioning worked.
That issue and one USB RTS restart that needed physical RESET remain documented.
The preparation record distinguishes these results from final release-image and
physical public-installer qualification. Battery-backed clock retention,
maximum output and an overnight soak were not established by those checks.

The approved normal/Fajr/dua recordings and redistribution permission are
unchanged. See [recording attribution and permission](../../AUDIO-LICENSES.md).
