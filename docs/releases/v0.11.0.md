# OpenAthan v0.11.0

## Automatic updates

OpenAthan can now install signed stable firmware releases automatically.
Automatic updates are on by default once this firmware is installed, including
on existing speakers updated through a preserving manual or USB update.

Installation waits until playback ends, the clock is valid and the next Athan
is at least 15 minutes away. A queued automatic update does not prevent Athan
from starting. Settings, credentials, prayer history and recordings are retained.

Use **Settings → Updates → Automatic updates** to turn it off. The saved choice
survives restarts and preserving updates. Turning it off cancels an automatic
download or queued update before restart begins. Explicit manual and USB update
requests remain available.

Canceled or rejected releases stay skipped automatically across restarts. A newer
release or an explicit manual installation can proceed. An interrupted image
verification requires a manual retry. Failed cancellation retains its request
and reports an error; uncertain boot selection retains its recovery record until
the speaker can establish which application is selected.

## Updating an existing speaker

Speakers on earlier firmware need one preserving update to receive this feature.
Use the signed application update in the speaker's settings or the preserving
USB updater. Choose the profile matching your hardware: AtomS3R C126 with Voice
Pyramid A167, Waveshare Box V2 or Waveshare AUDIO-Board.

**A fresh installation erases existing firmware, credentials, settings and prayer
history.** Use a preserving update for an existing configured speaker.

The approved normal, Fajr and dua recordings are unchanged. See
[recording attribution and permission](../../AUDIO-LICENSES.md).

## Testing and limitations

The [attended Box V2 record](../development/automatic-update-hardware-2026-11-13.md)
covers signed private-feed updates, interruption and rollback, durable opt-out,
settings/history/audio preservation, full retained-recording playback and a
continuous instrumented hour. Normal firmware and scheduling were restored.

Those tests used the merged updater source before this version-only release
change. The exact v0.11.0 binaries have not been installed in an attended hardware
session. Atom and AUDIO-Board automatic-update hardware qualification, full
public application OTA delivery and overnight reliability remain untested.
Build and capacity measurements are provided in each profile's release assets.

The prior AUDIO-Board time-synchronization issue remains unresolved: one unit
needed a full power-cycle before its clock synchronized. Automatic Athan and
automatic installation remain blocked until the speaker has a valid clock.
