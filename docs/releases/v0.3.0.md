# v0.3.0 candidate release notes

These notes describe the next reference firmware candidate. v0.2.1 remains the
published stable release. Exact merged-source production build/package validation,
physical orientation confirmation and the focused memory check are pending.
See the [preparation report](../development/v0.3.0-preparation-2026-10-03.md)
for candidate build measurements and release sequencing.

## Changes

- Add a dim, always-on status display for the verified GC9107 AtomS3R C126 +
  Voice Pyramid A167 reference unit. It shows the local clock, next prayer/time,
  skipped or disabled prayers, playback, setup/time readiness and faults.
- Keep ordinary connected screens quiet. Wi-Fi loss shows an `Offline` footer;
  scheduling and stored audio continue while the clock remains valid.
- Define the reference front as the side opposite the Pyramid's power/expansion
  ports. Rotation 0 is intended to make text upright with the power cord at the
  back. Brightness defaults to 10% through the existing build substitution.

The display is optional. Its failure does not block scheduling, audio, local
controls or update health. Existing controls and the device-local HTTP contract
are unchanged. Cold boots still require time synchronization before automatic
playback is ready.

## Updating

After publication, existing v0.2.1 owners can choose the signed application-only
update on their authenticated device page. Compatible updates preserve settings,
credentials, prayer-consumption history and shared audio. The approved normal
and Fajr recordings and storage formats are unchanged.

Fresh USB installation erases saved settings, credentials and prayer history.
For an existing speaker or an older bootloader/layout, follow the
[preserving update guidance](../development/firmware-upgrades.md) rather than
using fresh installation or historical full-flash recovery.

## Validation and limits

The [attended display run](../development/display-validation-2026-10-03.md)
recorded 31 minutes of isolated hardware observations, both full retained
recordings, front-button/browser controls and scheduled playback while offline.
Those measurements belong to the recorded instrumented source.

The [orientation correction](../development/display-orientation-validation-2026-10-03.md)
awaits physical confirmation from the side opposite the ports. The earlier
run's largest free PSRAM block retained a 1 MiB reduction despite near-baseline
free PSRAM; a focused longer run must establish whether that difference remains
bounded before publication. Long-term stability, maximum-load production
headroom, broader hardware/network coverage and newer ST7735 panels remain
unqualified. Earlier acceptance is reused only within its recorded scope.
