# OpenAthan v0.5.0

Published stable release: [v0.5.0](https://github.com/OpenAthan-Project/openathan/releases/tag/v0.5.0).

OpenAthan now supports **Waveshare ESP32-S3-Touch-LCD-1.85C-BOX V2**, alongside the AtomS3R C126 + Voice Pyramid A167. **Waveshare V1 is not supported.**

## What’s included

- Standalone scheduled Athan with stored normal and Fajr recordings, plus setup and settings from your phone.
- Waveshare’s round display with saved brightness and a 12- or 24-hour clock.
- BOOT button controls to stop playback, skip the next Athan or cancel a skip.
- Clock recovery after a restart using the onboard RTC, after initial internet time synchronization and while RTC power is retained.
- Signed Wi-Fi firmware updates for each supported board, preserving settings, Wi-Fi credentials, prayer history and recordings.
- USB setup that recognizes hardware running compatible OpenAthan. For a blank device or other firmware, you select the model before installation.

## Install and update

**[Install and set up OpenAthan](https://openathan.com/install/)** using desktop Chrome or Edge. For Waveshare Box V2, connect a USB data cable to the rear USB-C port.

**Fresh installation erases existing firmware, Wi-Fi credentials, settings and prayer history.** To preserve saved data, use the Wi-Fi updater in your existing production device’s settings. USB firmware updates that preserve saved data are not yet available through the public installer.

**Start at a low volume.** Waveshare now uses its full software volume range, so saved volume settings can sound louder than before.

## Current limitations

Touch input, microphones and SD card storage are not yet supported. RTC backup-battery operation, time retention while unplugged and long-term clock drift have not yet been verified.

Waveshare Box V2 installation, setup, signed updates, recovery from a power interruption before the update takes effect, and rollback when an update fails to start passed hardware testing.

For technical details, see the [firmware update documentation](https://github.com/OpenAthan-Project/openathan/blob/v0.5.0/docs/development/firmware-upgrades.md) and the manifests, build reports and checksums in the [published release assets](https://github.com/OpenAthan-Project/openathan/releases/tag/v0.5.0).
