# OpenAthan v0.5.0

Release candidate; not published.

Waveshare **ESP32-S3-Touch-LCD-1.85C-BOX V2** joins the AtomS3R C126 + Voice
Pyramid A167 reference build. V1 is not supported.

- Standalone scheduled Athan, approved stored recordings and local phone setup.
- Round display with saved brightness and 12/24-hour formatting.
- BOOT controls to stop playback, skip the next Athan or cancel that skip;
  RESET restarts the device.
- Onboard RTC startup recovery after internet synchronization, when RTC power
  is retained. Battery retention, unplugged retention and drift are unqualified.
- Board-specific signed application updates preserve production settings,
  credentials, playback history and shared audio.
- Browser setup recognizes hardware reported by compatible OpenAthan. Blank or
  vendor firmware requires model selection and full-erasure confirmation.
  USB preserving update writes remain disabled pending physical qualification.

Touch, microphones and SD storage remain deferred. The Waveshare volume mapping
now uses the full software volume range; retained settings can sound louder.
Start at a low volume. Listening with this mapping remains pending.

**Fresh installation erases existing firmware and saved data.** Isolated
development storage is not migrated into production. Existing production
speakers should use the [preserving update guidance](../development/firmware-upgrades.md).
Atom filenames and its existing update compatibility remain supported.

See [preparation and validation](../development/v0.5.0-preparation-2026-10-10.md)
for automated results, prior hardware evidence and remaining qualification.
