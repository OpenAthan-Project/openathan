This prepared Atom and Waveshare Box V2 production profiles, combined release

See the [published release notes](../releases/v0.5.0.md).

## Configuration and artifact contract

Both profiles retain two 2 MiB application slots and separate 3.5 MiB shared
audio. Atom remains 8 MiB; Waveshare is 16 MiB with the upper flash unused.
Waveshare production uses production namespaces, enabled signed updates, round
display, BOOT controls and the merged RTC adapter. Diagnostic and isolated
storage components are excluded; development records are not migrated.

Combined packaging keeps the seven Atom asset names and adds six files prefixed
`waveshare-box-v2.`. Both manifests reference identical approved audio. Signatures
bind hardware, layout, source, version and application hash; mismatched hardware
and source commits fail validation. See [release tooling](releases.md).

The browser recognizes the additive USB hardware field, preserves legacy Atom
responses, and requires explicit model selection for unknown firmware. It checks
ESP32-S3, selected flash capacity and security before any erase/write. Discovery
and recovery do not erase data. USB application writes stay disabled in public
policy until physical qualification. Stable publication remains the approval
gate for automatic website adoption.
