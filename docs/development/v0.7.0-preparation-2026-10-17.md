# v0.7.0 preparation — 2026-10-17

This prepares phone setup and speaker-page discovery for release review. Public
stable/latest remains v0.6.0. See the [candidate notes](../releases/v0.7.0.md) and
[release procedure](releases.md). Preparation does not publish firmware, create a
release tag, upload assets, select latest or install anything on a speaker.

## Source and compatibility

The feature source is merged main `b0cbbb7c81b8bddde7f3c2b85262caa5a2d9cbda`:
speaker-page discovery (#52), first-run phone setup (#53) and its explicit
release-manifest capability (#54). This preparation changes the four production
and inherited version fields to v0.7.0, updates the pinned installer consumer and
adds release documentation. Firmware logic, dependencies, trust, stored settings,
prayer history and recordings are unchanged by the preparation itself.

The measured version candidate is
`76c24ab6bdc4b2f89a332746b5c5831fffde8cff`, against the main source above. Later
preparation-document changes do not change firmware inputs. These are branch
preview artifacts; rebuild the exact selected main source after merge before
tagging or uploading a release.

Upgrade schema, storage format and shared-audio format remain 1. Both boards
retain both 2 MiB application slots and the separate 3.5 MiB shared-audio
partition. Existing configured speakers keep their credentials and do not reopen
first-run enrollment. Missing credentials and configured outages continue to use
the established USB recovery boundary.
