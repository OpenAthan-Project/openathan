# Voice Pyramid ESPHome Component

Planned hardware adapter for the M5Stack Voice Pyramid A167 when used with the AtomS3R C126 reference build.

M5Stack's current official documentation calls SKU A167 Echo Pyramid. OpenAthan retains Voice Pyramid as its project-facing name for the same product.

Responsibilities are expected to include LEDs, touch controls, display integration, and audio-hardware initialization as required.
